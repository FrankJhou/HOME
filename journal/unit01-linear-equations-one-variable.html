UNIT 01 · STAGE 1

一元一次方程式

Linear Equations in One Variable

台灣對應 南一/翰林 1上 第X章 Cambridge Stage 7 · Equations & Formulae A-Level 種子概念 解方程式技巧鋪路

一、核心觀念

Core Concept

什麼是「一元一次方程式」?

「一元」代表方程式中只有一個未知數(通常寫成 x);「一次」代表這個未知數的次方是 1(沒有 x²、x³ 這種項)。 例如 2x + 5 = 17 就是一個一元一次方程式——它只有一個未知數 x,而且 x 的次方是 1。

A linear equation in one variable contains only one unknown (usually written as x), and that unknown appears only to the first power (no x², x³, etc.). For example, 2x + 5 = 17 is a linear equation in one variable.

先從最簡單的例子開始:一台真的天平

想像你家有一台真正的天平秤。現在天平兩邊一樣重,所以指針停在正中間,保持水平。

假設左邊放了 3 顆彈珠,右邊也放了 3 顆彈珠——天平當然是平的,因為 3 = 3。

這時候,如果你偷偷在左邊多加了 2 顆彈珠,天平會立刻往左邊傾斜、失去平衡。 除非你也在右邊加上 2 顆彈珠,天平才會繼續保持水平(因為 3+2 = 3+2,也就是 5 = 5)。

Imagine a real balance scale. If both sides weigh the same, it stays level. If you secretly add 2 marbles to the left side, the scale tips — unless you also add 2 marbles to the right side.

這就是整個單元最重要的一句話:只要兩邊「同時」做一樣的事,天平就會繼續保持平衡。 方程式其實就是一台「用文字和數字寫出來的天平」,等號(=)就是那根指針——代表左右兩邊現在的重量相等。

This is the golden rule of this whole unit: as long as you do the same thing to both sides at the same time, the balance stays level. An equation is just a balance scale written with numbers and letters, and the "=" sign is the pointer showing both sides currently weigh the same.

把方程式當成天平來解:2x + 5 = 17

現在把同樣的概念套用到方程式 2x + 5 = 17 上。你可以想像成一家糖果店的秤重情境:

天平左邊放了「兩包一樣重的糖果」(每包都不知道多重,所以用 x 公克表示,兩包就是 2x)和一個「5 公克的小砝碼」; 天平右邊放了一個「17 公克的砝碼」。因為題目說這個方程式成立,所以天平現在是平衡的。

我們的目標很簡單:把左邊變成只剩一包糖果,這樣就能知道「一包糖果(x)到底是幾公克」。 而唯一能做的事,就是前面學到的黃金規則——兩邊同時做一樣的操作。

Picture a candy shop scale: the left pan holds 2 identical bags of candy (each weighing x grams) plus a 5g weight; the right pan holds a 17g weight. Since the equation is true, the scale is balanced. Our goal: get the left side down to just 1 bag, so we know what x is.

③ 一包糖果 = 6g ✓

第一步:右邊拿掉 5g 的話,天平會傾斜——所以左邊也要拿掉 5g,天平才會繼續平衡。這一步用掉的是「減法性質」:兩邊同時減去 5,變成 2x = 12。
第二步:現在左邊是「2包一樣重的糖果」,右邊是 12g。把兩邊都「平分成 2 份」(同時除以 2),就能知道一包糖果是幾公克——也就是 x = 6。

Step 1 (Subtraction Property): remove 5g from both sides → 2x = 12. Step 2 (Division Property): split both sides into 2 equal groups → x = 6. One bag of candy weighs 6 grams.

二、等量公理

Properties of Equality — The Four Legal Moves

解方程式時,只要對等號兩邊「同時做同一件事」,等式就會繼續成立——這就是上一節天平模型告訴我們的道理。 以下把這個道理拆成四種具體操作,每一種都附上「為什麼可以這樣做」的說明,而不只是死記公式。 Each property below explains not just what you can do, but why it keeps the equation balanced.

① 加法性質 Addition Property

內容:等號兩邊同時加上同一個數,等式仍然成立。

為什麼可以這樣做:想像天平兩邊本來就一樣重,如果你在兩邊各放上同樣重的東西,天平當然不會傾斜——兩邊只是一起變重了相同的量,彼此的差距完全沒有改變。

If both sides of a balance already weigh the same, adding the same extra weight to each side keeps it level — the gap between them never changes.

例 x − 3 = 5 → 兩邊同時 +3 → x = 8 左邊本來因為「少了3」而比較輕,兩邊都加回3後,天平就恢復平衡

② 減法性質 Subtraction Property

內容:等號兩邊同時減去同一個數,等式仍然成立。

為什麼可以這樣做:就像兩個人原本口袋裡的錢一樣多,如果兩人都花掉同樣的金額,他們剩下的錢還是一樣多。減去同一個數,只是把兩邊「同時拿走一樣多」,平衡自然不會被打破。

If two people start with equal amounts of money and each spends the same amount, they still have equal amounts left. Subtracting the same number from both sides doesn't change the balance.

例 x + 4 = 9 → 兩邊同時 −4 → x = 5 兩邊各拿掉4,天平仍然平衡

③ 乘法性質 Multiplication Property

內容:等號兩邊同時乘上同一個「非零」數,等式仍然成立。

為什麼可以這樣做:想像兩杯本來一樣多的果汁,如果你把兩杯都變成 3 倍大(例如各自倒入 3 個一樣的杯子),兩邊仍然一樣多,只是份量一起放大了相同的倍數。

為什麼不能乘以 0:如果兩邊都乘以 0,不管原本 x 是多少,兩邊都會變成 0——這樣 x 原本的資訊就整個消失了,方程式也失去意義。

If two equal cups of juice are both scaled up 3×, they stay equal. But multiplying both sides by 0 destroys all information about x — both sides become 0 no matter what x was.

例 x/3 = 4 → 兩邊同時 ×3 → x = 12 兩邊一起放大3倍,比例關係不變

④ 除法性質 Division Property

內容:等號兩邊同時除以同一個「非零」數,等式仍然成立。

為什麼可以這樣做:想像兩堆本來一樣重的沙子,如果把兩堆都平分成一樣的份數(例如都分成5等份),每一份的重量彼此仍然相等。

為什麼不能除以 0:「除以0」在數學上根本沒有意義(你無法把東西分成「0等份」),所以這個操作永遠被禁止。

Splitting two equal piles of sand into the same number of equal groups keeps each group equal. Dividing by 0 is undefined — you can't split something into "0 parts."

例 5x = 20 → 兩邊同時 ÷5 → x = 4 兩邊一起平分成5份,每份仍然相等

三、例題精解

Worked Examples — Step by Step

例題 1 · 基礎型2x + 5 = 17
12x + 5 − 5 = 17 − 5兩邊同時減去 5(減法性質)
22x = 12化簡兩邊
32x ÷ 2 = 12 ÷ 2兩邊同時除以 2(除法性質)
4x = 6檢驗:2(6)+5 = 17 ✓
例題 2 · 含括號3(x − 2) = x + 8
13x − 6 = x + 8先展開括號(分配律)
23x − x = 8 + 6把 x 項移到左邊、常數移到右邊(移項要變號)
32x = 14化簡
4x = 7檢驗:3(7−2)=15,7+8=15 ✓
例題 3 · 含分數(x + 1)/3 − 1 = x/2
1兩邊同乘以 6(3 和 2 的最小公倍數)消去分母,讓算式變乾淨
22(x + 1) − 6 = 3x6÷3=2,6÷2=3
32x + 2 − 6 = 3x展開括號
42x − 4 = 3x → −4 = x移項
5x = −4檢驗:(−4+1)/3−1 = −2,(−4)/2 = −2 ✓

四、應用題常見類型

Word Problem Types — Set Up the Equation First

應用題最重要的第一步,永遠是「設 x 代表什麼」,再把文字翻譯成方程式。以下是會考最常出現的五種題型:

類型 A · 年齡問題 Age Problem

爸爸的年齡是小明的3倍,5年後爸爸年齡是小明的2倍多3歲,求小明現在幾歲?

看解答過程
設小明現在 x 歲,爸爸現在 3x 歲。
5年後:3x + 5 = 2(x + 5) + 3
展開:3x + 5 = 2x + 13 → x = 8
答:小明現在 8 歲(爸爸 24 歲)。
類型 B · 追及問題 Catch-up Problem

弟弟先出發,每分鐘走60公尺;哥哥慢5分鐘出發,每分鐘走80公尺,求哥哥出發後幾分鐘追上弟弟?

看解答過程
弟弟先走5分鐘,已領先 60×5 = 300 公尺。
設哥哥走 t 分鐘追上弟弟:80t = 60(t + 5)
80t = 60t + 300 → 20t = 300 → t = 15
答:哥哥出發後 15 分鐘追上弟弟。
類型 C · 折扣問題 Discount Problem

一件衣服打8折後售價960元,求原定價?

看解答過程
設原定價 x 元:0.8x = 960
x = 960 ÷ 0.8 = 1200
答:原定價 1200 元。
類型 D · 分配問題 Distribution Problem

甲、乙兩人共有180元,甲比乙多20元,求兩人各有多少元?

看解答過程
設乙有 x 元,甲有 (x + 20) 元:x + (x + 20) = 180
2x + 20 = 180 → 2x = 160 → x = 80
答:乙有 80 元,甲有 100 元。
類型 E · 數字問題 Digit Problem

一個兩位數,十位數字是個位數字的2倍;若兩數字對調,新數比原數小27,求原數?

看解答過程
設個位數字 x,十位數字 2x(2x ≤ 9):原數 = 21x,對調後 = 12x
21x − 12x = 27 → 9x = 27 → x = 3
答:原數為 63(個位3、十位6)。

六、進階練習題(含應用題)

Advanced Practice — Including Word Problems

數字方程

解方程式:(x − 1)/2 = (x + 5)/4

看解答過程
兩邊同乘4:2(x−1) = x+5 → 2x−2=x+5 → x=7
連續整數問題

三個連續整數之和為72,求這三個數。

看解答過程
設三數為 n, n+1, n+2:3n+3=72 → n=23
答:23、24、25
工作分配問題

甲單獨完成一件工作要x天,已知甲工作3天後,剩下的量乙可以用2天完成,且乙的工作效率是甲的1.5倍,求x。

看解答過程
甲每天做 1/x,3天做了 3/x;剩下 1 − 3/x 由乙2天做完,乙每天做 1.5/x。
2 × 1.5/x = 1 − 3/x → 3/x + 3/x = 1 → 6/x = 1 → x = 6
答:甲單獨需要 6 天。
比例混合問題

某班男生比女生多8人,男生人數是女生人數的1.4倍,求全班共有多少人?

看解答過程
設女生 x 人,男生 1.4x 人:1.4x − x = 8 → 0.4x = 8 → x = 20
答:女生20人、男生28人,全班共 48 人。

Exam-Style Mock Questions — TW & Cambridge/IGCSE Format

仿會考 · 選擇題

若 3x − 7 = 2x + 5,則 x = ?

(A) −12(B) 12(C) −2(D) 2
看解答

仿會考 · 選擇題(應用)

小華買了6枝相同價格的筆,共花了150元。若每枝筆的價格為 x 元,下列何者正確表示這個關係?

(A) 6x = 150(B) x/6 = 150(C) 6 + x = 150(D) x − 6 = 150
看解答
選 (A);解得 x = 25。
仿會考 · 非選擇題

解方程式 2(x + 3) = 4x − 2,並完整列出解題過程。

看解答
2x + 6 = 4x − 2 → 6 + 2 = 4x − 2x → 8 = 2x → x = 4
仿 IGCSE · Structured Question

Solve the equation 5x − 3 = 2x + 12. Show your working. [2 marks]

Show Solution
5x − 2x = 12 + 3 → 3x = 15 → x = 5
仿 IGCSE · Word Problem

The sum of three consecutive integers is 72. Form an equation and solve it to find the three integers.

Show Solution
Let the integers be n, n+1, n+2. n + (n+1) + (n+2) = 72 → 3n + 3 = 72 → n = 23
The integers are 23, 24, and 25.
仿 IGCSE · Algebraic Fractions

Solve: (3x + 2)/4 = x − 1

Show Solution
3x + 2 = 4(x − 1) → 3x + 2 = 4x − 4 → 2 + 4 = 4x − 3x → x = 6

重點整理小卡 Quick Review Card

DEFINITION

一元一次方程式:只有一個未知數,且次方為1的方程式。

A linear equation in one unknown, where the unknown is only to the first power.

FOUR MOVES

等量公理:加、減、乘、除同一個數(乘除不能是0)。

Properties of equality: add, subtract, multiply, or divide both sides by the same number (never 0 for ×/÷).

HAS BRACKETS?

先展開括號(分配律),再移項化簡。

If there are brackets, expand them first (distributive law), then simplify.

HAS FRACTIONS?

先找分母的最小公倍數,兩邊同乘,消去分母。

If there are fractions, multiply both sides by the LCM of the denominators to clear them.

MOVING TERMS

移項時符號要改變(+變−,×變÷)。

When a term crosses the equals sign, its operation flips (+ becomes −, × becomes ÷).

WORD PROBLEMS

第一步永遠是:設 x 代表什麼,再把文字翻譯成算式。

Always start by defining what x represents, then translate the words into an equation.

ALWAYS CHECK

解出 x 後代回原式驗算,確保兩邊相等。

After solving for x, substitute it back into the original equation to check both sides match.

COMMON TYPES

年齡、追及、折扣、分配、數字問題是會考最常見的五種應用題。

Age, catch-up, discount, distribution, and digit problems are the 5 most common word-problem types.
